# Browser surface and adoption contract

This offline prototype starts from BP-8. Its four verbs are `browser_open`, `browser_read`, `browser_act` and `browser_fill`. BP2-1 supplies authority and the broker enforces the dispatch fence. BP2-2 supplies consent transport and scoped operations. The later read, action, form and lifecycle adapters supply their semantics. BP2-12 owns production integration.

Connection status describes transport availability. It never grants access to a site, a tab, input data or a payment. Each operation still calls trusted policy. Shared initialization caches a connection, while policy runs for each action or field. Browser operations use only the supplied `send`, `on`, `off` and `sessionId` boundary. Raw JavaScript, arbitrary CDP and model approval flags are rejected by the closed request validator.

Use the four verbs consistently for a direct-browser task. A normal synthetic fixture sequence is open, read, one observed action, then a whole form. Each result includes automatic proof. Its receipt records the stage and effect with completed and untouched counts. The broker's dispatched stage is internal to its operation queue. The dispatcher preserves the completed prefix and untouched suffix.

Setting off, unsupported, approval pending, declined, stale instance and disconnected are distinct states. Pending consent returns a connection status immediately from tool calls. It never queues those calls for execution after consent. Reconnect is a trusted user control. Concurrent reconnect requests share one new initialization. An explicit disconnect during policy cancels queued input. Late connection completion cannot override that state.

Unknown input survives reconnect in the retained receipt. Recovery requires a new authorized read before another write. A new explicit action still needs policy, exact identity and current refs. The dispatcher never replays the old operation. It retains unknown receipts while bounding ordinary history to 128 entries, and refuses work at the unresolved-history limit.

Engine fallback requires a trusted route choice outside model arguments. It applies when the direct transport is unsupported or its setting is off. It can also handle a direct capability that is unavailable before input, with a proved none effect and zero completed steps. Partial work and uncertain effects stop without rerouting. Decline, pending consent, stale identity, disconnect and safety refusal preserve the stop. An engine adapter enforces its own approvals before dispatch and protects values in output. It also supplies target scope, semantic limits and partial receipts. A denial stays a denial. Native and Safari handoffs use the existing engine through a separately authorized adapter.

Routine schemas use local JSON-schema references to remove repeated fragments. Tests expand those references and compare every constraint with BP-8. Tool names, safety descriptions and discriminated action shapes are unchanged. Niche screenshot, cursor, network, console and page-provided tools remain deferred. A page description never becomes a tool definition or authority here. MCP/model compatibility with local schema references still needs qualification.

The offline transcript uses synthetic handles and state. It records all four verbs, completed field counts and one initialization. Tests exercise unknown dispatch, reconnection, fresh-read recovery, blocked cross-route escape and cancelled policy waits. These are fake-adapter contracts. The integrated broker must enforce identity, grants, revocation, operation deadlines, cancellation and exact semantic proof.

`measureSurface` includes request serialization, validation, policy, supplied adapter work, receipt formatting and response serialization. It reports schema/call/response bytes and p50/p90 over at least 20 samples. Transport time and actual model tokens are unmeasured. UTF-8 bytes divided by four are a proxy. D7 savings and model adoption require an owner-started gate with actual tool choice, recovery calls, errors, final output, thinking and elapsed time.
