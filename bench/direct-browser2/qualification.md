control channel, private profile, local server and cleanup. Hold/away/live-lock rules still apply.

connected and idle status, zero-session connection retention, last-socket close, broker/browser

queues, refused permissions, unknown effects and all failures. Same-process fake clients and tiny
transport exchanges are separate component evidence. They cannot satisfy this matrix.

## Measurement clocks and proof

Keep human consent, cold machine attachment, full policy/adapter initialization and warm complete
tools separate. Record raw request/dispatch/settle/proof/delivery and admission timestamps where
the host exposes them. Unsupported spans remain null. Capture per-client queue tails, CPU time,
RSS, cold startup, payload bytes, result coverage, effect receipts and unrelated-target effects.
Compare complete calls with design v2's budget. Do not add D7/model projections again.

Use nearest-rank p50/p90, reporting N and ordered raw samples. Passing-call percentiles sit beside
total time including failures. Missing clocks/resources remain null. For every trial, independently
attest process incarnations, selected browser/root, policy configuration and exact cleanup. Missing
clients, duplicate client/trial records, shared processes or unequal cells require explicit incomplete
status. A host-authenticated collector must prove these identities outside the model interface.

Capture only owned windows if a separately scoped headed recording is dispatched. Do not capture
the desktop, owner data or unrelated windows. A final close acknowledgment is insufficient without
owned process/target absence and lock/profile cleanup receipts. Retain ownership on uncertain cleanup.

perf.mjs summarizes metadata without running a benchmark or browser. It always returns qualified:false.
Host metadata with complete cells can become eligibleForHostReview. That field is an accounting
check, not authorization, browser support or a speed claim. It rejects page-content fields and
accessors, and retains only the closed timing/control/outcome schema.
