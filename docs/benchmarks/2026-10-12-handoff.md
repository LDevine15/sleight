# Hand-off tasks: a web page, then a Mac app (2026-10-12)

These tasks start in a browser and finish in a Mac app. The invoice task downloads a PDF and reads it back in
Preview. The table and note tasks copy from a page into a new TextEdit document and save it. Each arm ran each
task once, one task at a time, on FowlBrowser's runner with sleight's patch ([bench/fowl/handoff.sh](../../bench/fowl/handoff.sh), tasks in
[bench/fowl/handoff.json](../../bench/fowl/handoff.json)). The grader checks the answer, the site's log and the
saved file.

FowlBrowser alone has no tool for Mac apps, so it can't finish any of these tasks. The FowlBrowser + sleight arm
uses FowlBrowser for the page and sleight for the app, with sleight's browser tools turned off
(`SLEIGHT_SURFACES=computer`).

## Setup

- The agent is Claude Code 2.1.289 (`claude -p`), Opus 5.5 at medium effort, on the owner's Claude account. Cost is
  Claude Code's own usage report.
- Every tool that reaches outside the browser or the app under test is blocked for every arm (Bash, Read, Write,
  Edit, Glob, Grep, Monitor, Agent and the rest in the patch). sleight's arms may also use sleight's `open_file`
  since `e815a8e`, after both runs here.
- An Elicitation hook ([bench/fowl/origin-hook.mjs](../../bench/fowl/origin-hook.mjs)) accepts the engine's site and
  download prompts for the benchmark's own pages on 127.0.0.1 and its app prompts for Chrome, Helium, Preview and
  TextEdit, and declines everything else.
- sleight: the private working branch at the time of each run (18:57: `1caa7b1` plus the hook change in
  `faeea9d`), engine 26.1007.30912. The owner was working on the Mac during both runs.
- Raw reports, home paths shown as `~`: [18:57 sleight](2026-10-12-handoff/18-57-sleight.md),
  [18:57 FowlBrowser + sleight](2026-10-12-handoff/18-57-fowl-sleight.md),

## What happened

- At 18:37 both sleight arms missed the invoice: the hook declined the engine's download prompt, which reads "Allow
  download from <url>?". The hook accepts it since `faeea9d`, and both arms passed it at 18:57.
- FowlBrowser's note task at 18:37 is graded ok in the raw report, but its agent wrote the file through
  Monitor's shell with `osascript`. We count it as a failure. The runner has blocked Monitor since.
- sleight's invoice run at 18:57 took 149 s of its 180 s budget. A `downloadMedia` call on the PDF link hung until the
  engine reset its kernel (32 s), and recovering the tab cost about 40 s more. Without `open_file` it opened the
  PDF through Preview's Open panel.
